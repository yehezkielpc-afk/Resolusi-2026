Izinkan Akses Kamera

Aplikasi ini membaca gerakan tangan lewat webcam untuk membentuk dan mengendalikan bangun ruang / huruf 3D secara langsung. Video kamera diproses di perangkat Anda sendiri (di browser) dan tidak dikirim atau disimpan ke server mana pun.

Gestur Satu Tangan

  • Jempol ke atas — objek berikutnya (A→B→C)
  • Jempol ke bawah — objek sebelumnya (Z→Y→X)
  • Telunjuk+tengah menyilang — ganti mode bangun ruang ⇄ huruf
  • Telunjuk+tengah tidak menyilang — ganti warna
  • Mengepal — geser objek (belum permanen)
  • Semua jari terbuka — rotasi objek

Gestur Dua Tangan

  • Shaka (jempol+kelingking) menjauh — perbesar
  • Shaka mendekat — perkecil
  • Kedua tangan terbuka, tidak menyilang — tempatkan objek permanen
  • Kedua tangan terbuka, menyilang — hapus objek terakhir

Keyboard (uji coba)

WASD geser · QE/RF rotasi · Z/X skala · ↑/↓ ganti objek · Tab mode · C warna · Space tempatkan · Backspace hapus
